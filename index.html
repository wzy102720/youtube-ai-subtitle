YouTube 双语字幕

将视频字幕翻译成你选的语言，让译文和原文按时间轴同步显示。

安装油猴脚本

当前版本 0.11.3 · 需要先安装 Tampermonkey 浏览器扩展

多语言双语字幕译文在上、原文在下，支持目标语言选择和简繁转换。
新版 DeepSeek默认使用 deepseek-flash，当前对应 DeepSeek-V4.1-Flash-1017。
切换视频自动衔接更换视频或字幕轨道时取消旧任务，避免旧译文覆盖当前内容。
保留进度继续翻译按批保存已成功译文，后台暂停、回到前台续译；完整缓存仍按引擎等设置隔离。
英语优先整句翻译合并自动字幕片段，避免在逗号处拆成半句；过长语流分段时，DeepSeek 参考相邻上下文。

开始使用

  1. 安装 Tampermonkey，再点击上方按钮安装脚本。
  2. 到 DeepSeek 开放平台创建 API Key。
  3. 打开 YouTube 视频，在油猴菜单中选择“设置 DeepSeek API Key”，输入 Key 后刷新。
  4. 开启播放器的 CC 字幕按钮，先显示原文，译文生成后自动更新。
  5. 需要其他目标语言时，通过“目标语言”菜单设置，例如 zh-CN、zh-TW、en 或 ja。

脚本处理常规视频页面，依赖视频已有字幕，不进行语音识别。

也可以使用 Google 翻译

在油猴菜单中切换到 google 并刷新，无需配置 API Key。不同引擎使用独立缓存；网络或限流错误不会保存为空译文。

等待与重试

尚未捕获字幕时保留原生字幕。等待超过 30 秒后再开启 CC，脚本仍会自动处理。翻译失败时优先使用“继续翻译未完成字幕”，保留成功译文；“清除当前视频缓存”会连同进度一起删除并从头翻译。

手机切后台时暂停请求，回前台继续；恢复事件漏发时也会检查可见状态并唤醒任务。页面被回收重载后，开启 CC 匹配原字幕以恢复进度。移动端后台恢复仍需安卓 Edge 实机验证，不保证持续后台运行。

字幕原文会发送到选定的翻译服务；API Key、缓存和未完成进度保存在本机油猴存储中。费用以服务商的当前价格为准。
